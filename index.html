React × Electron × opencode

React → Electron:
сборка .exe installer

Сайт-инструкция для студентов: как из обычного React-приложения, собирающегося в браузер, сделать настольную программу для Windows. Шесть шагов: ревизия проекта → миграция на Vite → обёртка Electron → NSIS-установщик → финальная проверка → своя иконка. Каждый шаг — отдельный промпт для opencode: копировать, вставить, отправить, проверить результат. Ничего вручную в терминале не печатается — opencode выполняет команды сам. Прогресс отмечается по мере выполнения и сохраняется в браузере.

Готово! У вас настольное приложение.

React-проект переведён на Vite, обёрнут в Electron, собирается в NSIS-установщик и распространяется как один .exe. Окно открывается, роутер работает, билд не пустой, иконка — ваша. Дальше: обновляете код — обновляйте версию в package.json → npm run dist → новый установщик готов к раздаче.
